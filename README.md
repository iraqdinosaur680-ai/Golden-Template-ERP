# Golden Template ERP | نظام القالب الذهبي المتكامل

نظام سحابي ومحلي متكامل لإدارة المعامل والشركات التجارية والمصانع الصغيرة والمتوسطة، يدعم اللغتين العربية والإنجليزية مع واجهة متوافقة بالكامل مع الاتجاهين (RTL/LTR).

---

## 🌟 أبرز مميزات النظام (Features)

1. **إدارة المنتجات والتكاليف الصناعية**: حساب تكلفة الإنتاج المعيارية والفعلية للمنتجات وتتبع المخزون والحد الأدنى.
2. **نقطة البيع والمبيعات (POS & Sales)**: إصدار فواتير بيع نقدية وآجلة، إدارة الخصومات، والطباعة الفورية.
3. **المشتريات والموردين (Purchases & Suppliers)**: تسجيل فواتير الشراء، إدارة الموردين، وإدخال المواد للمخازن.
4. **المصاريف والديون (Expenses & Debts)**: تصنيف النفقات التشغيلية، متابعة ديون العملاء والتزامات الموردين وتسديدها.
5. **شؤون الموظفين والرواتب (HR & Payroll)**: كادر الموظفين، سجل الحضور والانصراف، احتساب الرواتب والبدلات والخصومات.
6. **التقارير المالية والأرباح (Financial Reports & Statements)**: كشف حساب مالي تفصيلي، تقارير الأرباح والخسائر، وحركة المخزون.
7. **قوالب الطباعة والفواتير (Custom Print Templates)**: تصميم وتخصيص قوالب طباعة الفواتير والسندات بأحجام متعددة (A4 و Thermal 80mm).
8. **الأمان والصلاحيات (RBAC)**: نظام مستخدمين متقدم بصلاحيات دقيقة وتتبع سجل العمليات (Audit Logs).
9. **تزامن سحابي فوري ومستمر**: يعمل عبر Google Cloud Firestore مع دعم العمل دون إنترنت عبر التخزين المحلي (LocalStorage).

## 🔑 بيانات الدخول الافتراضية (Default Credentials)

| الدور (Role) | اسم المستخدم (Username) | كلمة المرور (Password) | الصلاحيات |
|---|---|---|---|
| **مدير النظام (Admin)** | `admin` | `adminpassword` | صلاحيات كاملة وشاملة لكل أقسام النظام |
| **الكاشير والمبيعات (Cashier)** | `cashier` | `cashierpassword` | فواتير المبيعات ونقاط البيع والديون |
| **المحاسب المالي (Accountant)** | `accountant` | `accountantpassword` | العمليات المالية، المشتريات، الموظفين والتقارير |

## 🚀 تشغيل المشروع محلياً (Getting Started)

### المتطلبات (Prerequisites)
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- `npm` أو `pnpm` أو `yarn`

### خطوات التثبيت والتشغيل
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. تشغيل خادم التطوير المحلي
npm run dev

# 3. بناء النسخة الإنتاجية
npm run build
```

## ⚙️ التكوين وإعداد السحابة (Configuration)

يعمل النظام تلقائياً ببيئة تجريبية محلية (Local Storage). لتفعيل المزامنة السحابية عبر Firebase Firestore:
1. انسخ ملف المتغيرات:
   ```bash
   cp .env.example .env
   ```
2. أدخل مفاتيح مشروع Firebase الخاص بك في ملف `.env`.
